# Central do Galo — v9

## Alterações desta versão

- Removidos do cabeçalho os cards de "notícias carregadas" e "fontes nesta tela".
- Layout do frontend refeito para comportamento responsivo em celular, tablet, notebook, desktop e monitores grandes.
- Breakpoints específicos para 1120px, 820px, 640px e 420px.
- Cards de notícia passam de duas colunas para uma coluna e, no celular, imagem acima do conteúdo.
- Navegação e categorias têm rolagem horizontal controlada em telas estreitas.
- Busca, fonte, botões, cabeçalho e rodapé dos cards se reorganizam para evitar overflow horizontal.
- Viewport móvel configurado explicitamente no Next.js.
- Mantida a regra visual: nenhuma cor azul na interface do portal. Fotografias jornalísticas permanecem em suas cores originais.
